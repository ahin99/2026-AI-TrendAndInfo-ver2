### 2. 효과적인 AI 활용법: 프롬프트 엔지니어링과 모델별 최적 전략

AI를 원하는 방향으로 다루기 위해서는 사용 중인 모델의 특성을 이해하고, 올바른 지침(Prompt)을 전달하는 기술이 필요합니다.

- **공식 문서가 말하는 프롬프트 작성법:**  
  OpenAI와 Anthropic(Claude)의 공식 가이드에 따르면, 프롬프트 작성 시 **대상 독자 명시, 상위 규칙 제시, 출력 형식 지정, 하지 말아야 할 범위 제한**을 명확히 정의하는 것이 좋습니다. 또한 프롬프트를 작성할 때 Markdown이나 XML 구조를 활용해 계층적으로 전달하면 AI의 가독성과 이해도가 크게 향상됩니다.

- **AI 모델 성능에 따른 지침의 구체성:**  
  - **높은 추론 수준의 모델(시니어 개발자 역할):** 최종 목표와 청사진 중심의 '고수준 지침(High-level instruction)'만으로도 맥락을 스스로 이해하고 세부 사항을 해결합니다.
  - **상상성이 낮거나 세부 지침이 필요한 모델(주니어 역할):** 모호한 지시보다는 명시적이고 정밀한 단계별 지시가 있어야 의도한 출력을 얻을 수 있습니다.

- **작업 목적에 맞는 모델 선택과 실전 검증:**  
  ChatGPT 6.1 Sol과 Claude Sonnet 5.5의 비교 사례처럼 단순 성능 비교보다 **내가 하려는 작업(코딩, 디자인, 영상 기획 등)에 어떤 모델이 더 적합한지** 직접 프롬프트를 넣어 테스트해보는 전략이 유효합니다. 스터디 내부에서도 /67, /crash-out 같은 특수한 프롬프트 명령어의 실제 유효성이나 유료 플랜 적용 여부를 직접 실험하며 검증하는 노력이 이뤄졌습니다.

### 3. Python AST 및 프로파일링 기반 알고리즘 성능 측정기
> **원문 제목:** 최적의 성능인지 나타내는 프로그램 (읽을거리 7)

#### 📌 핵심 내용 쉬운 정리
작성한 파이썬 코딩 알고리즘의 최적화 여부를 판단하기 위해 자동 분석 프로그램을 설계한 글입니다. 
파이썬 내부 모듈을 이용해 코드 안의 반복문 개수를 파악해 **시간복잡도를 추정(Big-O)**하고, 실제로 코드가 작동할 때 걸리는 **시간과 최대 사용 메모리(Peak Memory)를 측정**하여 최적화 가이드를 제공합니다.

#### 💡 이해를 돕는 배경지식
- **AST (Abstract Syntax Tree, 추상 구문 트리):** 소스 코드를 실행하지 않고, 코드의 문법적 구조를 나무(Tree) 형태의 데이터로 표현한 것입니다. 이를 통해 `for`, `while` 문이 몇 번 중첩되었는지 분석할 수 있습니다.
- **tracemalloc:** 파이썬에서 메모리 할당 상태를 추적하는 표준 라이브러리로, 특정 시점의 메모리 사용량과 최고 메모리 점유량을 측정해 줍니다.

#### 🔗 같이 알아두면 좋은 연계 지식
- **빅오 표기법 (Big-O Notation):** 입력 데이터 크기($n$)의 증가에 따라 알고리즘 실행 시간이 어떻게 늘어나는지 상한선을 표현하는 컴퓨터 과학의 표준 표기법입니다. ($O(1)$, $O(n)$, $O(n^2)$ 등)
